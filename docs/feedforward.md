# Прямая нейросеть для синтеза ДОЭ

Сеть за один проход превращает 4 целевых изображения 128×128 в фазу ДОЭ. Обучение идёт без голограмм-эталонов: фаза проходит через точную модель Френеля (`holo/optics.py`), потеря считается по метрикам задачи на восстановленных изображениях. После прохода сети фазу можно дообучить той же потерей под конкретную четвёрку.

Восстановление везде, как у жюри: модуль поля |K|, нормированный по максимуму, оценка из сохранённого 8-битного PNG (`holo.evaluate.evaluate`). Метрики по интенсивности |K|² приведены для справки.

## Архитектура

`holo/models/feedforward.py`, класс `FeedForwardDOE`. Это развёрнутый многоплоскостной Герчберг–Сэкстон, где каждый шаг обучаемый.

1. U-Net в плоскостях восстановления. Вход: цели T, нормированная амплитуда |K| и cos/sin фазы ∠K текущего поля в 4 плоскостях, две координатные карты (18 каналов). Выход: комплексный множитель u_z на каждую плоскость. Поле в плоскости: g_z = T_z · u_z · exp(j∠K_z).
2. Обратный перенос каждого g_z в плоскость ДОЭ точной моделью (`back_propagate`), сумма по плоскостям.
3. U-Net в плоскости ДОЭ поправляет комплексную сумму (вход Re, Im и координаты, выход добавка к Re, Im).
4. Фаза ДОЭ = atan2(Im, Re): разрыва на ±π сеть не видит.
5. Прямой перенос в 4 плоскости даёт K для следующего шага.

Выходные свёртки обоих U-Net инициализированы нулём, поэтому необученная сеть совпадает с GS из плоской фазы, и обучение стартует с него. Финальная конфигурация: 3 шага, U-Net ширины 32 и глубины 4 (каналы 32…256), 30,9 млн параметров.

Квантование в 8 бит учитывается при обучении: фаза округляется к 256 уровням PNG, градиент проходит насквозь (`quantize`).

## Данные

`scripts/make_dataset.py`, `holo/dataset.py`.

- Фото: DIV2K train HR (800 снимков 2K, [архив](https://data.vision.ee.ethz.ch/cvl/DIV2K/DIV2K_train_HR.zip)), по 40 случайных квадратных кадров разного масштаба на снимок, уменьшение до 128×128, почти однотонные кадры отброшены. 32 000 кадров.
- Символы: 30 000 картинок. Буквы кириллицы и латиницы, цифры, надписи из 2–4 знаков, наборы фигур; 22 шрифта, случайные размер, положение, яркость, поворот, размытие, инверсия. Arial Bold исключён: им нарисованы проверочные символы.
- Четвёрки собираются на лету: 50 % только фото, 25 % только символы, 25 % смесь. Аугментации: отражение, транспонирование, гамма, сжатие диапазона яркости, округление до 8 бит.

Проверка на данных, которых сеть не видела:

| группа | что внутри |
|---|---|
| photos | `data/targets/photos` (camera, astronaut, coffee, coins) |
| glyphs | `data/targets/glyphs` (Л, А, З, Р шрифтом Arial Bold) |
| heldout_kodak | Kodak, 24 фото → 6 четвёрок ([источник](https://r0k.us/graphics/kodak/)) |
| heldout_glyphs | 4 четвёрки случайных символов и фигур шрифтом Arial Bold |
| heldout_mixed | 2 четвёрки «2 фото + 2 символа» |

## Обучение

`scripts/train_ff.py`. Потеря на четвёрку: среднее по плоскостям (1 − КК) + (1 − SSIM), обе метрики дифференцируемые и совпадают с проверочными (`holo/losses.py`). AdamW, пакет 16, косинусное расписание, MPS.

Финальная модель обучалась в два этапа (все запуски обучения вместе заняли около 1,5 ч, GPU делили с другими задачами):

1. 1000 шагов с нуля, lr 1e-3, потеря по интенсивности (`c_s3doe`, 22 мин), затем 1500 шагов дообучения, lr 5e-4 (`intensity_final`, 24 мин).
2. После уточнения условия (жюри сравнивает |K|) 4800 шагов с потерей по амплитуде, lr 5e-4 (`final`, 44 мин).

Чекпоинт: `outputs/ff/final/model.pt` (не в git, `outputs/` в `.gitignore`). Повтор:

```bash
PYTHONPATH=. uv run python scripts/make_dataset.py
PYTHONPATH=. uv run python scripts/train_ff.py --name c_s3doe --stages 3 --steps 1200 --minutes 22 --eval-every 200
PYTHONPATH=. uv run python scripts/train_ff.py --name final --stages 3 --init outputs/ff/c_s3doe/model.pt --lr 5e-4 --steps 4800
```

Второй этап по интенсивности при повторе можно пропустить: амплитудное обучение стартует с любого обученного чекпоинта.

## Дообучение под конкретные изображения

`holo/refine.py`.

- `refine_phase`: Adam по фазе от ответа сети, косинусное затухание шага, начальный шаг 0,2. Это вариант по умолчанию в `scripts/infer.py` (1000 шагов).
- `refine_weights`: дообучение копии сети на одной четвёрке. Каждый шаг стоит прохода сети вперёд и назад, поэтому при равном времени проигрывает дообучению фазы.

## Синтез

```bash
PYTHONPATH=. uv run python scripts/infer.py <папка с 4 PNG> <выходная папка> [--refine 1000] [--checkpoint outputs/ff/final/model.pt]
```

Изображения сопоставляются плоскостям 24,1; 25,3; 26,5; 27,7 мм в порядке сортировки имён. В выходной папке: `doe.png` (0 → −π, 255 → +π), 4 восстановления `recon_<имя>_<z>mm.png` (|K|, нормировка по максимуму, 8 бит), `metrics.json` с КК и SSIM по каждой плоскости, средними, временем и метриками по интенсивности.

## Результаты

Все числа: среднее КК / SSIM по 4 плоскостям, оценка из 8-битного PNG. Время на CPU (8 потоков) общей машины, под нагрузкой других задач, поэтому сравнивать его надо между строками, а не с другими отчётами. Проход сети: 39 мс на MPS, 0,5–0,7 с на CPU. ## Выводы

- Один проход сети (39 мс на MPS) по качеству между GS 50 и GD 50: на фото КК ниже, SSIM выше.
- На натуральных изображениях сеть + N шагов идёт вровень с GS 50 + GD N начиная с 200 шагов; к 1000–3000 шагам все методы сходятся к одному уровню (фото 0,60 / 0,42). Сеть не находит лучший оптимум, она даёт старт.
- На бинарных символах старт решает исход: сеть + 200 шагов даёт SSIM 0,714 против 0,577 у GS 50 + GD 200 и 0,085 у GD со случайного старта, при КК 0,647 против 0,694 и 0,795. Преимущество держится и при 3000 шагах.
- На отложенных символах и фигурах шрифтом Arial Bold (`heldout_glyphs`, там есть инвертированные картинки и фигуры) сеть уступает GS 50 + GD: 0,459 / 0,250 против 0,473 / 0,322 при 1000 шагах.
- Лучшая конфигурация: 3 развёрнутых шага с U-Net в обеих плоскостях, обучение через физическую модель по амплитуде, затем 200–1000 шагов Adam по фазе с шагом 0,2 и косинусным затуханием.

## Риски

- Высокий SSIM на символах при амплитудной метрике достигается так: в каждой плоскости есть яркое пятно, после нормировки по максимуму фон становится почти чёрным, и окна SSIM на фоне совпадают с целью. Сами буквы при этом тусклые, и во всех 4 плоскостях видна смесь всех букв. GS 50 + GD использует тот же приём. Метрики это засчитывают, но глазом картинка хуже, чем у GD со случайного старта (у того КК выше). Если жюри будет смотреть на изображения, нужен штраф на отношение пика к среднему.
- По амплитуде сеть обучалась 44 минуты на общем GPU, кривая потерь ещё снижалась. Больше шагов, вероятно, поднимут качество прохода без дообучения.
