# Синтез ДОЭ под одну сцену: что даёт нейросетевая параметризация и где потолок

Документ отвечает на два вопроса: какая параметризация фазы и какая потеря дают максимум метрик
при оптимизации под конкретную четвёрку изображений, и чем ограничено качество в принципе.
Все числа получены через `holo.evaluate.evaluate`: фаза сохраняется в 8-битный PNG, восстановление
считается из этого PNG и округляется до 8 бит, метрики — `skimage` SSIM и коэффициент Пирсона.

Запуск: `PYTHONPATH=. uv run python scripts/per_instance.py data/targets/photos data/targets/glyphs data/targets/extra`.
Железо: Apple M4 Max, PyTorch MPS, float32.

## Наборы

| набор | что это |
|---|---|
| photos | полутоновые фотографии skimage: camera, astronaut, coffee, coins |
| glyphs | бинарные символы Л, А, З, Р |
| extra | другой источник, снимки с другой статистикой: chelsea, rocket, moon, cell |
