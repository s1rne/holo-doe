# Нейросетевой синтез многоплоскостного фазового ДОЭ: обзор и рекомендации

Задача: один фазовый ДОЭ 128×128 восстанавливает 4 разных полутоновых изображения 128×128 на расстояниях 24,1; 25,3; 26,5; 27,7 мм; λ = 532 нм, пиксель ПВМС 10 мкм, дифракция Френеля с одним БПФ; метрики КК (Пирсон) и SSIM. Текущий результат в репозитории: фото КК ≈ 0,49, SSIM ≈ 0,29 (градиентный спуск по фазе); бинарные глифы КК ≈ 0,76, SSIM ≈ 0,73.

## 0. Физика задачи: откуда берутся перекрёстные помехи

Числа посчитаны для параметров условия.

| величина | значение |
|---|---|
| критическое расстояние z_c = Nδ²/λ | 24,06 мм |
| пиксель в плоскости восстановления λz/(Nδ) | 10,0; 10,5; 11,0; 11,5 мкм |
| числовая апертура ДОЭ (Nδ/2)/z | ≈ 0,027 |
| продольное разрешение λ/NA² | ≈ 0,75 мм |
| шаг между плоскостями | 1,2 мм ≈ 1,6 продольного разрешения |
| разность квадратичных фаз на краю ДОЭ, соседние плоскости | 4,3–4,8 рад (≈ 0,7 длины волны) |
| то же, крайние плоскости 24,1 и 27,7 мм | 13 рад (≈ 2 длины волны) |
| радиус расфокусировки «чужой» плоскости в пикселях выхода | ≈ 3 px (соседняя), ≈ 8 px (крайняя) |

Выводы:

1. Первое расстояние 24,1 мм совпадает с критическим z_c = Nδ²/λ: при нём масштабный множитель μ = Nδ²/(λz) из работ лаборатории равен 1, квадратичная фаза дискретизирована точно по Найквисту. Похоже, параметры выбраны из этого соображения (в статье Злоказова, Старикова, Черёмхина и др. 2025 г. по camera-in-the-loop тот же масштаб μ = KΔ²/(λz₀), объекты 64×64 внутри поля 128×128, λ = 532 нм; см. §1).
2. Плоскости друг от друга всего в 1,6 продольного разрешения. При гладкой фазе изображение одной плоскости в соседней размыто лишь на ~3 пикселя, то есть «призрак» структурирован. При случайной фазе картина другая: спекл декоррелирует уже на 1,2 мм. Проверка (§5): ДОЭ, оптимизированный только под плоскость 24,1 мм, даёт там КК 0,99, а в плоскостях 25,3/26,5/27,7 мм КК 0,04/0,01/0,01. Значит, сами плоскости развести можно; предел качества при 4 изображениях задаёт не структурный призрак, а нехватка степеней свободы (п. 4): 128² фаз делятся на 4 изображения, и каждое получает остаточный спекл.
3. В схеме с одним БПФ пиксель ДОЭ с координатой u отвечает пространственной частоте поля в плоскости восстановления. Квадратичные фазы разных плоскостей у центра ДОЭ почти совпадают, поэтому низкие частоты поля общие для всех 4 плоскостей. Различать плоскости можно только высокочастотной частью поля. Отсюда практическое правило: гладкая фаза (smooth phase), которая лучше всего подавляет спекл в одной плоскости, в многоплоскостной задаче почти не даёт развести изображения; случайная (широкополосная) фаза разводит их, но приносит спекл, который бьёт по SSIM.
4. Число степеней свободы: 128² фазовых отсчётов против 4·128² целевых интенсивностей. Точное решение невозможно в принципе; любая хорошая методика ищет компромисс «спекл ↔ перекрёстные помехи». Разреженные цели (глифы) проще: тёмный фон не требует степеней свободы, их хватает на светлые штрихи.
5. Метрики КК инвариантны к аффинному преобразованию яркости, SSIM нет (константы c₁, c₂ привязаны к диапазону 0..255, окно 7×7). Нормировка восстановленного изображения по максимуму делает результат чувствительным к одиночным спекл-пикам: один яркий пиксель затемняет всё изображение и снижает SSIM.

### 1.3. Что из этого следует для ожиданий жюри

- **Метрики.** Группа регулярно использует SSIM, КК, NSTD, спекл-контраст и дифракционную эффективность. NSTD у них считается по матрицам a₀ и aₙ, обозначенным как изображения (σ = 1 − (Σa₀aₙ)² / (Σa₀²·Σaₙ²)); в той же статье эффективность считается по интенсивности Iₙ. Явного правила «сравнивать |K|² или |K|» в открытых текстах нет. В условии сказано «восстановленные изображения получены численным расчётом дифракции Френеля», то есть естественное прочтение: интенсивность |K|², как на камере. Рекомендация в §4: основной результат по |K|², в приложении тот же ДОЭ, оценённый по |K|.
- **Случайная начальная фаза.** В итеративных методах группы GS стартует со случайной фазы объекта («оптимизация начального случайного распределения фазы»), в многоплоскостных методах (parallel ping-pong, Makowski) тоже. Для жюри это нормальная практика.
- **Планка качества.** Для полутоновых изображений группа публикует SSIM 0,2–0,6 и считает это рабочим уровнем; NSTD 0,05–0,09 достигается в одноплоскостных бинарных задачах. Для 4 плоскостей с шагом 1,2 мм открытых чисел у группы нет. Наш SSIM 0,29 по фото уже в этом диапазоне; честное сравнение с GS и parallel ping-pong будет убедительнее абсолютных цифр.
- **Скорость.** В 3D-CGH-Net выигрыш у GS заявлен как «более чем в 3 раза» на 16 плоскостях. Значит, жюри примет и умеренное ускорение, если качество не хуже.
- **Совпадение параметров.** Первое расстояние 24,1 мм равно Nδ²/λ (μ = 1) для N = 128, δ = 10 мкм, λ = 532 нм. Конкретной статьи с набором 24,1/25,3/26,5/27,7 мм найти не удалось: полные тексты 3D-CGH-Net и статьи в «Измерительной технике» 2023 закрыты, сборники конференции ФИО (fioconf.mephi.ru) отдают 403. Шаг 1,2 мм и 4 плоскости похожи на постановку из 3D-CGH-Net или работ по parallel ping-pong.

### 2.2. Итеративные многоплоскостные методы, с которыми надо сравниваться

- Fresnel ping-pong: Dorsch, Lohmann, Sinzinger, Appl. Opt. 33, 869 (1994), [doi:10.1364/AO.33.000869](https://doi.org/10.1364/AO.33.000869). Обобщение на 3 и больше плоскостей: Makowski, Sypek, Kolodziejczyk и др., *Three-plane phase-only computer hologram generated with iterative Fresnel algorithm*, Opt. Eng. (2005), [ResearchGate](https://www.researchgate.net/publication/238981751_Three-plane_phase-only_computer_hologram_generated_with_iterative_Fresnel_algorithm); *Design and applications of multi-plane Fresnel color holograms* (2008), [Semantic Scholar](https://www.semanticscholar.org/paper/Design-and-applications-of-multi-plane-Fresnel-Makowski-Sypek/ef1bfbbbaab5f96c8835973d3669e9c3fe4bbb54). Это и есть «parallel ping-pong» из работы лаборатории. Наш `gerchberg_saxton` в `holo/baselines.py` по сути параллельный вариант (поля плоскостей суммируются). Стоит добавить и последовательный (sequential) вариант: жюри его знает.
- Non-convex optimization: Zhang, Pégard, Zhong, Adesnik, Waller, *3D computer-generated holography by non-convex optimization*, Optica 4, 1306 (2017), [doi:10.1364/OPTICA.4.001306](https://doi.org/10.1364/OPTICA.4.001306). Это наш `gradient_descent`.
- Makey et al., *Breaking crosstalk limits to dynamic holography using orthogonality of high-dimensional random vectors*, Nat. Photon. 13, 251 (2019), [doi:10.1038/s41566-019-0393-7](https://doi.org/10.1038/s41566-019-0393-7). Каждой плоскости своя случайная фаза; перекрёстные помехи становятся некоррелированным фоном благодаря почти-ортогональности случайных векторов большой размерности; 1000 плоскостей. Для нас: случайная фаза переводит структурированный призрак в некоррелированный спекл-фон, и это подтверждается нашей проверкой (КК чужой плоскости 0,01–0,04, §5). Остаётся цена: спекл в каждой плоскости.
- Оговорка про ортогональность из мета-голограмм: перекрёстные помехи растут, когда соседние изображения похожи (пример «P» между «O» и «Q»), см. [arXiv 2007.00130](https://arxiv.org/pdf/2007.00130). Значит, метрики будут зависеть от набора 4 изображений жюри, и это надо показать.

### 2.3. Приёмы против перекрёстных помех и спекла

Гладкая фаза почти не различает плоскости в 1,2 мм. |
| Свободная фаза в плоскости изображения (оптимизация только по амплитуде/интенсивности) | Главный источник качества GD/SGD против GS. | Уже есть: GD по фазе ДОЭ с потерей только по интенсивности. |
| Оптимальный масштаб в потере (s·|K|² против цели) | Снимает конфликт «энергия ↔ форма». У Peng et al. масштаб s оптимизируется. | У нас нормировка по максимуму; см. §4 про штраф пиков. |

Главный аргумент против «U-Net на GS»: задача 4 плоскостей с шагом 1,6 продольного разрешения находится на грани разрешимости, и решения GS здесь слабые (наши 200 итераций GS заметно хуже GD). Сеть, обученная копировать слабого учителя, не может его превзойти.

### 3.1. Как выиграть, не выходя за условие «нейросетевой метод»

Предлагаемая схема: **обученный физически-информированный генератор + адаптация на этапе вывода (test-time optimization)**.

1. Сеть-генератор G_θ (U-Net или многоветвевая сеть по образцу 3D-CGH-Net: по ветви на плоскость, слияние в фазу ДОЭ) обучается без эталонных голограмм на большом процедурном датасете 128×128: фотографии (DIV2K, BSDS, COCO в оттенках серого), текст и глифы, процедурные фигуры с широким спектром, MNIST/EMNIST. Потеря: метрики задачи (1−КК)+(1−SSIM) по |K|² после нормировки по максимуму, дифференцируемо через модель Френеля из условия. Наборы из 4 изображений составляются случайно, так что сеть учится разводить любые 4 изображения.
2. На этапе вывода сеть выдаёт ДОЭ за миллисекунды. Это и есть «нейросетевой метод», конкурентный по скорости.
3. Опциональный режим «качество»: несколько десятков шагов дообучения весов сети (или скрытого входа) на конкретных 4 изображениях с той же физической потерей. Это стандартная техника test-time training / deep image prior (Ulyanov, Vedaldi, Lempitsky, *Deep image prior*, CVPR 2018, [arXiv:1711.10925](https://arxiv.org/abs/1711.10925)); в CGH так делают DL-WGS (сеть + итеративная доводка) и camera-in-the-loop оптимизация в Neural holography. Параметризация фазы через свёрточную сеть служит регуляризатором и даёт другой ландшафт оптимизации, чем фаза-как-параметр.

Аргументы легитимности для жюри:
- Решение ДОЭ всегда выдаёт нейросеть: фаза = G_θ(изображения). Итерации меняют веса сети, а не фазу напрямую.
- Режим без дообучения показывается отдельной строкой таблицы: «сеть, 1 проход». Он уже должен быть лучше GS по качеству и на порядки быстрее.
- Дообучение показывается как кривая «качество от числа шагов» рядом с кривой GS: на любом бюджете времени наш метод выше.

### 4.1. Интенсивность или амплитуда

- Камера регистрирует |K|², в работах лаборатории для дифракционной эффективности используется интенсивность. Основной результат: |K|², нормировка по максимуму.
- Если жюри сравнивает |K| с объектом, ДОЭ, оптимизированный под |K|², теряет часть метрик (и наоборот). Проверочные числа в §5. В отчёте дать обе оценки одного ДОЭ и сказать, какую считаем основной.
